# SNUG WRLD — Streetwear Storefront

Responsive static streetwear storefront inspired by the visual reference.

## Run
Open `index.html` in a browser. The page uses inline CSS and JavaScript, so no build step or framework is required.

## Included
- Responsive editorial landing page
- Product grid and category filters
- Product details with size selection
- Client-side shopping bag with quantity controls and subtotal
- Product search
- Newsletter interaction (demo only)

## Before production
- Replace demo copy, product photos, product names and prices with assets and information you own or are licensed to use.
- Checkout is a demo; connect Stripe, Shopify, or another commerce provider before accepting orders.
- Newsletter signup does not store addresses; connect an email marketing provider.
- Add real shipping, returns, privacy, cookie, and terms pages before taking orders.
